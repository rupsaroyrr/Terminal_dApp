01. Executive Overview & Features

The Stellar Network Payment Terminal is a dystopian-themed, high-density Web3 application unifying native Stellar payments, Soroban smart contract interactions, multi-pay batch execution, interactive diagnostics, and digital asset marketplaces.

🔗 Multi-Wallet Uplink ⚡

Seamlessly connects Freighter, Rabe, Hana, xBull, and Albedo wallets using a unified modal provider.

🛡️ Soroban Relief Protocol 📜

Pools communal funds transparently via TranscendenceContract with real-time goal tracking.

🏪 NFT Marketplace (ICC) 💎

Inter-contract communication between USD-calibrated NFTShop and tokenized StellarNFT.

📱 SEP-0007 Split Engine 📐

Generates shareable payment URIs and live QR codes for instant communal expense settlement.

🧪 Admin Diagnostics Suite ⚙️

Interacts with Soroban RPC to test Wasm security bounds (Malicious init, Pause toggle, Auth traps).

🎯 Hunters Protocol 📊

Triple-redundant whale telemetry scanner combining StellarExpert, ledger scanning, and local fallbacks.

06. Utility Services & Core Modules

src/utils/retryHelper.js — Exponential Backoff 
export async function withRetry(fn, options = {}) {
  const { maxRetries = 3, initialDelayMs = 300, backoffFactor = 2 } = options;
  let attempt = 0, delay = initialDelayMs;

  while (true) {
    try {
      return await fn();
    } catch (error) {
      attempt += 1;
      if (attempt > maxRetries) throw error;
      await new Promise(r => setTimeout(r, delay));
      delay *= backoffFactor;
    }
  }
}

10. Troubleshooting FAQ

Q: How do I test the Admin Diagnostics Panel?

Connect your wallet using the deployer address GBJB6GI3RUZGFRHXXTGW6CR646DV64BHJEVOTQFKLZMU6OF4QJHKFJOQ. The admin-only ⚠ DIAGNOSTICS tab will automatically decrypt in the UI.

Q: What should I do if Horizon RPC throws rate limit errors?

The dApp's sessionStorage caching layer (60m TTL) and withRetry backoff helper automatically absorb transient rate limits. You can also configure custom RPC nodes in Network Settings.
